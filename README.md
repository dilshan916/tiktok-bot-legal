## 🌟 Overview

This repository hosts the official public **Privacy Policy**, **Terms of Service**, and **Domain Verification Assets** required for applications connecting to the **TikTok Developer Platform** and automated publishing bots.

To satisfy TikTok developer review guidelines and OAuth application audits, public-facing applications must host verifiable, HTTPS-enforced legal declarations outlining user data handling, cookie policies, third-party disclosures, and deletion procedures.

---

## ✨ Included Legal Documentation

* 🛡️ **Privacy Policy**: Clear disclosures regarding user privacy rights, data collection boundaries, and analytics compliance.
* 📄 **Terms of Service**: Standard terms governing automated service access, API consumption limits, and acceptable use guidelines.
* 🔐 **Domain Ownership Verification**: Root-level validation token (`tiktok*.txt`) verifying domain sovereignty for the TikTok Developer Console.

## 🛠️ Maintenance & Verification Updates

When renewing or re-verifying application credentials in the TikTok Developer Portal:
1. Update `index.html` with updated contact or policy details.
2. If TikTok issues a new domain verification string, place the corresponding `tiktok<verification_hash>.txt` file in the root directory.
3. Commit and push changes to the `main` branch. GitHub Pages will build and deploy the update within seconds.
